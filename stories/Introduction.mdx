# shindonghyeo-ui

신동혁의 개인 React 디자인 시스템입니다. [개발 블로그](https://shindonghyeo.github.io)의 디자인을 다른 React 사이트에서도 쓸 수 있게 토큰과 컴포넌트로 정리했습니다.

왼쪽 목록에서 컴포넌트를 고르면 미리보기와 props 표가 나옵니다. **Controls** 패널에서 props를 바꿔 볼 수 있고, 위쪽 툴바의 **Theme** 버튼으로 라이트/다크 모드를 전환할 수 있습니다.

## 설치

```bash
npm install shindonghyeo-ui
```

```tsx
import 'shindonghyeo-ui/styles.css';
import { Button } from 'shindonghyeo-ui';

<Button variant="primary" href="/blog">글 둘러보기 →</Button>
```

## 구성

| 분류 | 컴포넌트 |
| --- | --- |
| Foundations | 색, 글꼴, 모서리 둥글기 등 디자인 토큰 |
| Layout | Container, Navbar, Banner, SectionTitle, Footer |
| Actions | Button, IconButton, ThemeToggle |
| Display | Chip, Logo, GradientText, PostList, Icons |
| Content | Prose, Toc, ReadingProgress |

자세한 사용법은 [GitHub README](https://github.com/SHINDongHyeo/shindonghyeo-ui#readme)에 있습니다.
